Fast-Entering Deep Doze

OxygenOS 15 normally waits 30–60 minutes of stillness before entering Deep Sleep. This tuning drops the trigger window to 2 minutes, cutting daytime pocket idle drain by up to 45%.

Parameter OxygenOS Default Ultra Doze Profile
Inactive Timeout (to sleep) 1,800,000 ms (30 min) 60,000 ms (1 min)
Sensing Timeout 300,000 ms (5 min) 0 ms (Instant)
Locating Timeout 30,000 ms (30 sec) 0 ms (Skip)
Deep Doze Frequency Rarely in daytime Every pocket session
PROPOSED COMMAND (REVIEW-ONLY) 
adb shell settings put global device_idle_constants inactive_to=60000,sensing_to=0,locating_to=0,motion_inactive_to=0,idle_after_inactive_to=0
1-TO-1 ROLLBACK COMMAND 
adb shell settings delete global device_idle_constants
